STAGE HINT & GUIDE

Stage 9: Validasi PIN ATM (Loop & Counter Percobaan)

GUIDE: 9. Validasi PIN ATM (3x Salah)

Sistem meminta input PIN (PIN benar: 1234). Percobaan dibatasi 3 kali. Jika PIN benar, cetak 'Selamat Datang'. Jika salah 3 kali, cetak 'Rekening Diblokir'.

LANGKAH SOLUSI DISARANKAN:
  • Inisialisasi 'salah = 0' dan 'berhasil = 0' dengan blok Process.
  • Buat While: kondisi '(salah < 3) && (berhasil == 0)'.
  • Di dalam While: Input 'pin'. Buat If: 'pin == 1234'.
  • Jika Benar: Output 'Selamat Datang' lalu Process 'berhasil = 1'.
  • Jika Salah: Output 'PIN Salah!' lalu Process 'salah = salah + 1'.
  • Setelah keluar dari While: Buat If 'berhasil == 0' -> Output 'Rekening Diblokir'.
